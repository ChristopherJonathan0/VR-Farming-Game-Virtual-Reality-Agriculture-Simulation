## 📖 Project Overview

This project is a **Virtual Reality (VR) farming game** designed to provide an immersive and interactive agricultural simulation experience. Developed using **Blender**, **Unity Engine**, and **C#**, the application allows users to learn and practice basic farming activities in a safe, virtual environment. 

This project is developed as part of an academic requirement (Thesis/Skripsi) to explore the implementation of VR technology in educational and simulation-based applications.

## ✨ Key Features

*(💡 *Catatan: Silakan hapus atau ubah fitur di bawah ini sesuai dengan apa yang **benar-benar** kamu buat di game-mu*)*

- **Immersive VR Environment:** Fully explorable 3D farm environment designed with attention to detail.
- **Interactive Farming Mechanics:** Plant seeds, water crops, and harvest mature plants using VR controllers.
- **Intuitive Controls:** Easy-to-learn VR interactions (grabbing, pointing, and teleportation).
- **Educational Simulation:** Learn the basic lifecycle of agricultural activities.
- **Custom 3D Assets:** Environment and props modeled and textured using Blender.
